# VS Code Workbench Behaviors

- Primary and secondary sidebars toggle independently from the title bar.
- Hiding the primary sidebar leaves the activity rail in place and returns width to the editor.
- Sidebars resize from their inner borders and preserve their most recent width.
- The secondary sidebar can maximize into the workbench and restore to its previous width.
- Editor groups split horizontally, resize independently, and close when their final tab closes.
- Increasing the current editor view can temporarily collapse its sibling group.
- Moving a tab to a new window creates an editor-only auxiliary window with its own tab strip and split controls.
- Interactive icons use neutral hover/selected surfaces; the product intentionally omits VS Code blue accents.
- Focus outlines remain visible for keyboard users.
- Dark and light appearances use the exact Default 2026 surface tokens.
