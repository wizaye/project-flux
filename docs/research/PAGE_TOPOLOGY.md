# VS Code Workbench Topology

1. Title bar — fixed 35px desktop chrome with centered command field and pane toggles.
2. Workbench — fills the viewport between title and status bars.
3. Activity bar — sticky 48px rail; remains visible when the primary sidebar closes.
4. Primary sidebar — resizable Explorer pane, default 296px.
5. Editor — flexible center region; supports multiple independently resizable groups.
6. Secondary sidebar — resizable Chat pane, default 300px; can maximize or close.
7. Status bar — fixed 32px footer shared by every workbench region.

The primary sidebar, editor groups, and secondary sidebar are horizontal resizable regions.
The activity bar and status bar never resize. Narrow screens hide both sidebars by default.
