# Glossary

## Document

A file stored in a vault.

## Journal Entry

A Document intentionally recorded for a calendar date. Any number of Journal Entries may share the same date.

## Calendar Entry

The calendar projection of a dated Document. A Calendar Entry is classified as either a Journal Entry or another dated Document.

## Tag

A reusable classification attached to a Document. The interface may display a Tag as a chip or label; “label” is not a separate metadata concept.
